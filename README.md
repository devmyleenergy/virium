## GitHub Pages

Coloque os arquivos desta pasta na raiz de um repositório. No GitHub, abra **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch **main**, a pasta **/(root)** e salve.

O endereço publicado aparece nessa mesma tela quando a publicação terminar. Use esse endereço no campo de site do cadastro do token.

Para alterar a página, edite `index.html`. Não há etapa de instalação ou compilação.
